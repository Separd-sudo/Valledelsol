   -> URL: https://github.com/Separd-sudo/Valledelsol.git

2. REPOSITORIO COMPONENTE FRONTEND
   -> URL: https://github.com/Separd-sudo/Valledelsol.git (Si está en el mismo, especificar la subcarpeta /frontend)
   -> Descripción: Aplicación construida en Next.js utilizando estándares de empaquetado NPM para la interfaz de usuario[cite: 67, 90].

3. REPOSITORIO MICROSERVICIO DE USUARIOS (ms-usuarios)
   -> URL: https://github.com/Separd-sudo/Valledelsol.git (Especificar subcarpeta /ms-usuarios)
   -> Descripción: Módulo encargado de la gestión, validación y autenticación de usuarios. Cuenta con persistencia independiente en PostgreSQL (usuarios_db) y la suite de pruebas unitarias con JaCoCo activa[cite: 38, 71, 90].

4. REPOSITORIO MICROSERVICIO DE REPORTES (ms-reportes)
   -> URL: https://github.com/Separd-sudo/Valledelsol.git (Especificar subcarpeta /ms-reportes)
   -> Descripción: Módulo responsable del procesamiento de reportes ambientales. Integra comunicación asíncrona mediante Apache Kafka, persistencia aislada en PostgreSQL (reportes_db) y reportes de cobertura automatizados[cite: 20, 38, 90].
